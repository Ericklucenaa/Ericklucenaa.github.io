03 Missões

★ MISSÃO PRINCIPAL · CONCLUÍDA

Cypress + ServeRest: testes E2E e de API

Suíte de automação para uma loja virtual com API REST e front-end em React. Os testes de interface criam a massa de dados pela API e só usam o navegador para o que estão testando: são rápidos, independentes e limpam tudo o que criam.

OBJETIVOS CUMPRIDOS

  • 27 testes: 15 de API e 12 de interface
  • Testes de contrato com JSON Schema (Ajv)
  • cy.intercept para inspecionar e simular respostas da rede
  • Pipeline no GitHub Actions: lint, suítes em paralelo e relatório publicado
  • TypeScript estrito, ESLint, Prettier e Page Objects
