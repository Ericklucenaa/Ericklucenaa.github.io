Sobre mim

Qualidade como parte do processo, não como etapa final

Sou analista de sistemas focado em garantia de qualidade de software, em Belo Horizonte. Trabalho com testes funcionais e de regressão, análise de requisitos e regras de negócio, e automação de testes web com Cypress, sempre dentro de times ágeis.

Antes da tecnologia, fui gerente administrativo por sete anos e instrutor de informática. Daí vem o meu olhar para processos, comunicação e a experiência de quem usa o sistema. Hoje também uso IA para ganhar produtividade na criação de cenários e na análise de falhas.

Cypress + ServeRest: testes E2E e de API

Suíte de automação para uma loja virtual com API REST e front-end em React. Os testes de interface criam a massa de dados pela API e só usam o navegador para o que estão testando: são rápidos, independentes e limpam tudo o que criam.
